#### Two new foods have been added to Minecraft: Peach Crisp and Golden Peach Crisp.

Update log:

**1.2.2**：
- Add "Obtain Golden Peach Crisp" to the achievement acquisition method for "Peach Crisp!".

**1.2.1**：
- Add the Golden Peach Crisp to the chest of the ruined portal.

**1.2**：
- Added some language translations.

**1.2-pre-2**：
- Optimized and refactored the code.
- Added some language translations.

**1.2-pre-1**：
- The package name has been modified.

**1.2-snapshot-7**：
- Pig Spirits are now attracted to Golden Peach Crisps, but you cannot barter them with Golden Peach Crisps.
- If the Pig Spirit takes away your Golden Peach Crisps, it will drop a corresponding number of Golden Peach Crisps when it dies.

**1.2-snapshot-6**：
- Add golden peach crisp to the "balanced diet" advancement.

**1.2-snapshot-5**：
- Fixed the bug where the "Peach Crisp" achievement could not be obtained and displayed.

**1.2-snapshot-4**：
- Add the mod [Homepage](https://modrinth.com/mod/peach-crisp) into the code.

**1.2-snapshot-3**：
- Add acoikonjac123 as another mod author in the code.

**1.2-snapshot-2**：
- The unlocking method for the recipes of Peach Crisp and Golden Peach Crisp has been changed.
- The unlock method for Golden Peach Crisp has been changed to: obtain a gold ingot, peach crisp, or golden peach crisp.
- The unlock method for Peach Crisp has been changed to: obtain either cookies, pink petal, or peach crisp.

**1.2-snapshot-1**：
- Add golden peach crisp.
The synthesis recipe for Golden Peach Crisp is the same as that for Golden Apple, except that the filling is peach crisp instead.
- Eating Golden Peach Crisp now can restore 8 nutrient and 12 saturation, and Haste II for 3:00, Resistance I for 1:00, and Health Regeneration II for 0:10.

**1.1**：
- Fix the resource pack version number.

**1.1-snapshot-4**：
- "In transactions with master farmers, there is a 50% chance to purchase 8 peach crisp with 5 emerald." This restriction allows for 24 transactions.

**1.1-snapshot-3**：
- In a transaction with a master farmer, there is a 50% chance to purchase 8 peach crisp with 5 emerald.
- Add peach crisp to the chests in villages, abandoned mines, dungeons, desert temples, and ancient cities.

**1.1-snapshot-2**：
- Fixed the bug in the "Balanced Diet" challenge, which is now displayed normally.

**1.1-snapshot-1**：
- When obtaining the pink flower cluster, the Peach Crisp will be displayed in the recipe book.

**1.0**：
- Upon obtaining Peach Crisp, the progress "Peach Crisp!" is achieved, which is inherited from "Husbandry".
- Add peach crisp to the "balanced diet" advancement. (There is a bug that prevents this challenge from being displayed.)

**1.0-snapshot-2**：
- Optimized the texture mapping.

**1.0-snapshot-1**：
- Add peach crisp, and combine two peach crisp with four pink petals and one cookie.
- Consuming it will grant 3 seconds of regeneration II.

#### 为我的世界新增了两款食物：桃酥和金桃酥。

更新日志：

**1.2.2**：
- 将“获得金桃酥”加入到“桃酥！”成就的获取方式中。

- 将金桃酥加入到废弃传送门的箱子中。

**1.2**：
- 加入了一些语言翻译。

**1.2-pre-2**：
- 对代码进行了优化和重构。
- 加入了一些语言翻译。

**1.2-pre-1**：
- 修改了程序包名。

**1.2-snapshot-7**：
- 猪灵现在会被金桃酥吸引，但你无法用金桃酥和它们以物易物。
- 如果猪灵拿走了你的金桃酥，它死后将掉落对应数量的金桃酥。

**1.2-snapshot-6**：
- 在“均衡饮食”中添加金桃酥。

**1.2-snapshot-5**：

**1.2-snapshot-2**：
- 更改了桃酥和金桃酥的配方解锁方式。
- 金桃酥解锁方式变更为：获得金锭或桃酥或金桃酥。
- 桃酥解锁方式变更为：获得曲奇或粉红色花簇或桃酥。

- 修复资源包版本号。

**1.1-snapshot-4**：

**1.1-snapshot-3**：

- 在村庄，废弃矿井，地牢，沙漠神殿和古城的箱子中添加桃酥。

**1.1-snapshot-2**：
- 修复了“均衡饮食”挑战的Bug，现在可以正常显示了。

**1.1-snapshot-1**：
